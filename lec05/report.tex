\section{Model wygenerowany przez sztuczną inteligencję - ChatGPT}

\subsection*{Wprowadzenie}
Model Data Vault 2.0 to podejście do budowy hurtowni danych, które:
\begin{itemize}
  \item dobrze się skaluje,
  \item umożliwia przyrostowe tworzenie systemu,
  \item oddziela ładowanie danych od logiki biznesowej,
  \item wspiera pełen audyt danych (insert-only),
  \item pozwala na automatyzację dzięki szablonom.
\end{itemize}

\subsection*{Model Skarbca Danych dla Uczelni}

\subsubsection*{Huby (klucze biznesowe)}
\begin{itemize}
  \item \textbf{Hub\_Student} – StudentID (np. numer indeksu),
  \item \textbf{Hub\_Kurs} – KursID (np. kod kursu),
  \item \textbf{Hub\_Profesor} – ProfesorID (np. numer pracownika).
\end{itemize}

\subsubsection*{Linki (relacje)}
\begin{itemize}
  \item \textbf{Link\_Student\_Kurs} – relacja zapisów studentów na kursy,
  \item \textbf{Link\_Kurs\_Profesor} – przypisanie profesora do kursu.
\end{itemize}

\subsubsection*{Satelity (atrybuty z historią zmian)}
\begin{itemize}
  \item \textbf{Sat\_Student\_Dane} – imię, nazwisko, adres, data urodzenia, timestamp,
  \item \textbf{Sat\_Kurs\_Dane} – nazwa kursu, opis, ECTS, timestamp,
  \item \textbf{Sat\_Profesor\_Dane} – imię, nazwisko, tytuł, timestamp,
  \item \textbf{Sat\_Student\_Kurs\_Status} – status zapisu (zapisany, zaliczony itp.), data zmiany.
\end{itemize}

\subsection*{Sposoby modyfikacji danych}
Data Vault opiera się na zasadzie \textbf{insert-only}:
\begin{itemize}
  \item \textbf{Huby} – dane są niemodyfikowalne, tylko dodawane, jeśli pojawia się nowy klucz.
  \item \textbf{Satelity} – każda zmiana atrybutu skutkuje dodaniem nowego rekordu z aktualną datą ważności (pełna historia zmian).
  \item \textbf{Linki} – nowa relacja (lub zmiana statusu relacji) dodawana jest jako nowy rekord.
\end{itemize}

\subsection*{Propozycja rozszerzenia modelu}

Dodajemy nowy hub: \textbf{Hub\_Wydział} – WydziałID (np. kod wydziału).

\subsubsection*{Nowe linki}
\begin{itemize}
  \item \textbf{Link\_Profesor\_Wydział} – relacja zatrudnienia profesora w danym wydziale.
\end{itemize}

\subsubsection*{Nowy satelita}
\begin{itemize}
  \item \textbf{Sat\_Wydział\_Dane} – nazwa wydziału, adres, dziekan, timestamp.
\end{itemize}
